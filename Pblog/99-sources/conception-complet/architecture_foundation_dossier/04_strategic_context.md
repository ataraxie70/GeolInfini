# 04 - Strategic Context

## 1. Analyse SWOT

| **Strengths (Forces)** | **Weaknesses (Faiblesses)** |
| :--- | :--- |
| - Centralisation complète des preuves de compétence. | - Effort important pour maintenir la qualité narrative. |
| - Modèle de "portfolio vivant" (projets en cours). | - Risque d'obsolescence rapide si non mis à jour. |
| - Pont unique entre blog (réflexion) et portfolio (résultat). | - Absence initiale de trafic/visibilité. |
| - Haute transparence du raisonnement intellectuel. | - Dépendance totale à la discipline du propriétaire. |

| **Opportunities (Opportunités)** | **Threats (Menaces)** |
| :--- | :--- |
| - Capacité à se différencier dans un marché saturé de CV standard. | - Évolution des plateformes (ex: LinkedIn) ajoutant des fonctions similaires. |
| - Attraction de collaborations de niche basées sur la compétence réelle. | - Émergence de l'IA générative rendant les contenus "standards" sans valeur. |
| - Construction d'un "Personal Brand" fort et authentique. | - Burnout du propriétaire face à la charge de documentation. |

## 2. Analyse PESTEL

| Dimension | Impact | Analyse |
| :--- | :--- | :--- |
| **Politique** | Faible | Peu d'impact direct, sauf régulations sur la localisation des données. |
| **Économique** | Moyen | Potentiel d'augmentation des revenus via clients/emplois. Coût de démarrage quasi nul. |
| **Social** | Fort | Tendance "Build in Public". Demande croissante d'authenticité et de preuves tangibles face aux personas corporate. |
| **Technologique** | Fort | L'IA augmente la valeur du raisonnement humain vérifié face au contenu automatisé. |
| **Environnemental** | Faible | Empreinte carbone minimale si le site est optimisé et léger. |
| **Légal** | Moyen | Conformité RGPD (données visiteurs), respect du Copyright, TOS des services tiers intégrés. |

## 3. Synthèse Stratégique

La plateforme s'inscrit dans une tendance lourde de la Tech : le passage du **"CV de déclarations"** (je sais faire X) au **"CV de preuves"** (voici comment j'ai fait X, pourquoi, et où vous pouvez le vérifier). 

L'avantage concurrentiel ne réside pas dans la technologie utilisée pour le site, mais dans la **densité de preuves** et la **qualité du raisonnement** exposés.
