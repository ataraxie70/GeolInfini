# Cahier des charges
## Plateforme de vente d’ordinateurs, d’accessoires audio et de services techniques

### 1. Contexte et justification du projet
Dans un marché où de nombreux acheteurs hésitent entre plusieurs marques et références d’ordinateurs, la plateforme proposée a pour objectif d’aider l’utilisateur à choisir un ordinateur adapté à ses besoins réels, et non seulement à sa perception d’une marque réputée. Le projet vise aussi à rassurer les clients sur les ordinateurs neufs et reconditionnés, tout en proposant des accessoires audio liés à l’usage informatique, comme les casques et écouteurs, ainsi que des services de maintenance et de support.

### 2. Vision du projet
Créer une plateforme moderne, claire et utile qui combine :
- la vente d’ordinateurs neufs et reconditionnés ;
- la vente d’accessoires audio pour ordinateur ;
- la mise à disposition de services techniques ;
- un accompagnement au choix grâce à des conseils, comparaisons et contenus pédagogiques.

### 3. Objectifs du projet
#### Objectif général
Aider chaque utilisateur à trouver l’ordinateur le plus adapté à son usage, à son budget et à son niveau de connaissance.

#### Objectifs spécifiques
- guider l’achat selon l’usage : bureautique, gaming, programmation, multimédia, mobilité, création de contenu ;
- renforcer la confiance autour du reconditionné ;
- proposer des casques et écouteurs adaptés à l’usage informatique ;
- permettre la demande d’accessoires non affichés en stock principal ;
- proposer des services de maintenance et de nettoyage ;
- fournir un contenu éducatif simple et utile.

### 4. Positionnement
La plateforme ne doit pas être perçue comme une simple boutique en ligne, mais comme un **conseiller d’achat technologique**. Elle se distingue par :
- une approche orientée besoin ;
- une pédagogie simple ;
- une forte attention à la confiance ;
- une présentation claire des performances et usages ;
- une valorisation des produits reconditionnés lorsqu’ils sont fiables.

### 5. Périmètre du projet
#### Inclus
- ordinateurs neufs ;
- ordinateurs reconditionnés ;
- casques et écouteurs pour ordinateur ;
- demande ou recherche d’accessoires à la commande ;
- services de maintenance légère ;
- contenu conseil et éducatif ;
- comparaison de produits ;
- recommandation personnalisée.

#### Exclu à ce stade
- vente directe d’accessoires gaming comme activité principale ;
- marketplace ouverte à des vendeurs externes ;
- vente de produits non liés à l’univers informatique.

### 6. Cibles utilisateurs
#### Profils principaux
- étudiants ;
- professionnels de bureau ;
- développeurs et programmeurs ;
- gamers ;
- créateurs de contenu ;
- acheteurs à budget limité ;
- clients recherchant du reconditionné fiable ;
- clients souhaitant un accompagnement avant achat.

### 7. Besoins utilisateurs
Les principaux besoins identifiés sont :
- comprendre quel ordinateur choisir ;
- comparer facilement plusieurs modèles ;
- savoir si le neuf ou le reconditionné convient le mieux ;
- trouver un produit compatible avec son budget ;
- acheter un casque ou un écouteur adapté à son usage ;
- demander un accessoire spécifique ;
- faire nettoyer ou entretenir son appareil ;
- bénéficier d’explications simples sur les composants techniques.

### 8. Fonctionnalités attendues
#### 8.1 Moteur de recommandation
Un assistant de choix devra proposer des ordinateurs selon :
- l’usage ;
- le budget ;
- le niveau de mobilité ;
- la préférence neuf / reconditionné ;
- les besoins en performance.

#### 8.2 Comparateur de produits
L’utilisateur doit pouvoir comparer plusieurs ordinateurs ou accessoires selon :
- CPU ;
- RAM ;
- stockage ;
- carte graphique ;
- écran ;
- autonomie ;
- poids ;
- garantie ;
- état ;
- prix.

#### 8.3 Filtres de recherche
La recherche doit permettre de filtrer par :
- usage ;
- budget ;
- marque ;
- taille d’écran ;
- mémoire RAM ;
- stockage ;
- état ;
- type de produit ;
- présence ou non d’une garantie.

#### 8.4 Catalogue produits
Le catalogue doit présenter :
- les ordinateurs ;
- les casques et écouteurs ;
- les services techniques ;
- les produits ou accessoires proposés à la commande.

#### 8.5 Demande d’accessoires sur commande
Le site doit permettre au client de formuler une demande pour un accessoire non affiché en stock principal.

#### 8.6 Demande de maintenance
Le client doit pouvoir demander :
- nettoyage interne ;
- diagnostic ;
- entretien ;
- assistance logicielle ;
- conseil après achat.

#### 8.7 Contenu éducatif
La plateforme doit contenir :
- guides d’achat ;
- explications sur les composants ;
- conseils sur le reconditionné ;
- vidéos ou supports pédagogiques.

### 9. Arborescence fonctionnelle
- Accueil
- Trouver mon ordinateur
- Comparer
- Ordinateurs neufs
- Ordinateurs reconditionnés
- Casques et écouteurs
- Services techniques
- Guides d’achat
- Conseils et vidéos
- Contact / assistance
- Garantie et retour

### 10. Règles de gestion
- chaque produit doit être rattaché à une catégorie claire ;
- chaque ordinateur doit comporter une fiche technique complète ;
- les produits reconditionnés doivent afficher leur état, leur garantie et les tests réalisés ;
- les casques et écouteurs doivent être présentés comme accessoires audio liés à l’usage informatique ;
- les accessoires gaming non tenus en stock principal doivent être traités via demande spéciale ;
- tout service technique doit faire l’objet d’une demande formalisée.

### 11. Exigences de contenu
Chaque fiche produit doit contenir :
- nom du produit ;
- description simple ;
- spécifications techniques ;
- usage recommandé ;
- points forts ;
- état du produit ;
- garantie ;
- prix ;
- disponibilité.

Chaque guide d’achat doit contenir :
- un contexte d’usage ;
- les critères de choix ;
- les erreurs fréquentes à éviter ;
- une recommandation finale simple.

### 12. Exigences UX / UI
L’interface doit être :
- simple ;
- moderne ;
- lisible ;
- rassurante ;
- adaptée mobile et desktop ;
- orientée décision rapide.

Principes recommandés :
- peu de texte par écran ;
- boutons clairs ;
- icônes utiles mais non excessives ;
- hiérarchie visuelle forte ;
- parcours très court vers la recommandation.

### 13. Exigences techniques
- site responsive ;
- système de gestion de contenu ;
- base de données produits ;
- moteur de filtrage et de recommandation ;
- espace d’administration ;
- sécurité des données ;
- sauvegarde régulière ;
- performances optimisées pour mobile.

### 14. Exigences de sécurité et de confiance
- affichage clair des conditions de garantie ;
- informations complètes sur les produits reconditionnés ;
- protection des formulaires et des données client ;
- traçabilité des demandes de maintenance ;
- validation des mises à jour catalogue.

#### Priorité haute
- moteur de recommandation ;
- catalogue ;
- comparaison ;
- fiches produits ;
- contenu de confiance ;
- demande de contact ;
- base des services.

#### Priorité moyenne
- vidéos ;
- avis clients ;
- automatisation avancée ;
- personnalisation plus poussée.

### 17. Indicateurs de succès
Le projet pourra être jugé réussi si :
- les utilisateurs trouvent rapidement un ordinateur adapté ;
- les demandes de conseil diminuent en complexité ;
- les produits reconditionnés sont mieux acceptés ;
- les demandes de maintenance sont bien structurées ;
- les conversions augmentent ;
- les visiteurs passent du contenu conseil à l’achat.

### 18. Évolutions futures possibles
- espace client ;
- historique des achats ;
- alertes de prix ;
- recommandation plus intelligente ;
- prise de rendez-vous pour maintenance ;
- blog plus complet ;
- intégration de vidéo conseil ;
- extension à d’autres accessoires informatiques.

### 19. Conclusion
Ce projet doit être conçu comme une plateforme d’aide à la décision, de vente et de service. Sa force réside dans la clarté de l’information, la confiance autour des produits, et la capacité à orienter chaque utilisateur vers le bon choix selon son besoin réel.
