# Final Product Structure

The platform is effectively divided into four products:

1. **Member Mobile App** (daily usage)
2. **User Web Portal** (advanced management)
3. **Admin Operations Dashboard** (supervision)
4. **Merchant & Partner Portal** (goods and service fulfillment)

This separation keeps each interface focused on its users while sharing a single visual design system and trust-oriented user experience.
