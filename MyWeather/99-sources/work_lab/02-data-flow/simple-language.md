# Guide de Simplification du Langage Météo

## Objectif

Ce document fournit un **guide pratique** pour transformer le jargon technique météo en langage simple et compréhensible par tous les utilisateurs.

---

## 1. Principes de Base

### Règle d'Or

> **Un citoyen ordinaire ne doit pas avoir besoin de dictionnaire pour comprendre la météo.**

### Niveaux de Lecture

| Niveau | Exemple | À éviter |
|--------|---------|----------|
| **Primaire** | "Il fait chaud" | "Température élevée" |
| **Secondaire** | "Le vent souffle fort" | "Vent de force 7 Beaufort" |
| **Grand public** | "Risque de pluie" | "Précipitations probables" |

## 2. Transformations par Concept

### 2.1 Température

| Technique | Simplifié | Très simple |
|-----------|-----------|-------------|
| 314.15 K | 41°C | Il fait très chaud |
| 293.15 K | 20°C | Il fait frais |
| 303.15 K | 30°C | Il fait bon |
| "Température maximale journalière: 42°C" | "Maximum aujourd'hui: 42°C" | "Il fera jusqu'à 42°C" |
| "Ressenti thermique: 45°C" | "Ressenti: 45°C" | "On ressent 45°C" |

### Templates de Phrases

```
❌ "La température ambiante est de 41 degrés Celsius"
✅ "Il fait 41°C"
✅ "Il fait très chaud (41°C)"

❌ "Le mercure devrait atteindre 43 degrés en milieu d'après-midi"
✅ "Il fera jusqu'à 43°C cet après-midi"

❌ "Température minimale de 28°C enregistrée à 6h"
✅ "Minimum de 28°C ce matin"
```

### Échelles Descriptives

```
Température (°C) → Description
─────────────────────────────────────────
< 15    →  "Il fait froid"
15-20   →  "Il fait frais"
20-25   →  "Il fait bon"
25-30   →  "Il fait chaud"
30-35   →  "Il fait très chaud"
35-40   →  "Chaleur importante"
40-43   →  "Chaleur extrême"
> 43    →  "Chaleur dangereuse"
```

### 2.2 Humidité

| Technique | Simplifié | Très simple |
|-----------|-----------|-------------|
| "Humidité relative: 23%" | "Humidité: 23%" | "L'air est sec" |
| "Humidité relative: 85%" | "Humidité: 85%" | "L'air est très humide" |
| "Point de rosée: 18°C" | — | "L'air est lourd" |

### Templates de Phrases

```
❌ "L'humidité relative est de 20%, indiquant un air très sec"
✅ "L'air est très sec (20%)"

❌ "Une humidité de 80% rendra la chaleur oppressive"
✅ "Avec 80% d'humidité, la chaleur sera difficile à supporter"

❌ "Le point de rosée élevé suggère une sensation de lourdeur"
✅ "L'air est lourd, vous vous sentirez moite"
```

### Échelles Descriptives

```
Humidité (%) → Description
─────────────────────────────────────────
< 20    →  "L'air est très sec"
20-30   →  "L'air est sec"
30-50   →  "Humidité confortable"
50-70   →  "L'air est légèrement humide"
70-85   →  "L'air est humide"
> 85    →  "L'air est très humide, temps lourd"
```

### 2.3 Vent

| Technique | Simplifié | Très simple |
|-----------|-----------|-------------|
| "Vent: 5 m/s, 270°" | "Vent d'Ouest à 18 km/h" | "Vent d'Ouest" |
| "Rafales à 50 km/h" | "Coups de vent à 50 km/h" | "Rafales à 50 km/h" |
| "Force 5 Beaufort" | "Vent modéré" | "Ça souffle" |

### Templates de Phrases

```
❌ "Le vent souffle du secteur Ouest à 22 kilomètres par heure"
✅ "Vent d'Ouest à 22 km/h"

❌ "Des rafales atteignant 60 km/h sont attendues"
✅ "Des coups de vent jusqu'à 60 km/h"

❌ "Le vent forcira en soirée pour atteindre 40 km/h"
✅ "Le vent se renforcera ce soir (40 km/h)"
```

### Échelles Descriptives

```
Vent (km/h) → Description
─────────────────────────────────────────
< 5     →  "Vent calme ou absent"
5-15    →  "Légère brise"
15-30   →  "Vent modéré"
30-50   →  "Vent fort"
50-80   →  "Vent très fort"
80-120  →  "Vent violent"
> 120   →  "Vent extrême, ouragan"
```

### Directions Simplifiées

```
Degrés → Technique → Simplifié
─────────────────────────────────────────
0°      →  Nord (N)       →  "du Nord"
45°     →  Nord-Est (NE)  →  "du Nord-Est"
90°     →  Est (E)        →  "d'Est"
135°    →  Sud-Est (SE)   →  "du Sud-Est"
180°    →  Sud (S)        →  "du Sud"
225°    →  Sud-Ouest (SW) →  "du Sud-Ouest"
270°    →  Ouest (W)      →  "d'Ouest"
315°    →  Nord-Ouest (NW)→  "du Nord-Ouest"
```

### 2.5 Précipitations

| Technique | Simplifié | Très simple |
|-----------|-----------|-------------|
| "Précipitations: 15mm" | "Pluie: 15mm" | "Il est tombé 15mm de pluie" |
| "Probabilité: 80%" | "Risque: 80%" | "Fortes chances de pluie" |
| "Cumul 24h: 62mm" | "Pluie en 1 jour: 62mm" | "62mm en 24h" |

### Templates de Phrases

```
❌ "Une probabilité de précipitations de 70% est attendue"
✅ "Risque important de pluie (70%)"

❌ "Des cumuls pluviométriques de 50mm sont prévus"
✅ "Il pourrait tomber 50mm de pluie"

❌ "Les précipitations seront intermittentes"
✅ "Il pleuvra par moments"
```

### Échelles Descriptives

```
Probabilité (%) → Description
─────────────────────────────────────────
0       →  "Pas de pluie prévue"
1-20    →  "Faible risque de pluie"
20-50   →  "Risque de pluie"
50-80   →  "Fort risque de pluie"
80-100  →  "Pluie certaine"

Quantité (mm en 24h) → Description
─────────────────────────────────────────
< 1     →  "Quelques gouttes"
1-10    →  "Pluie légère"
10-30   →  "Pluie modérée"
30-50   →  "Fortes pluies"
50-100  →  "Pluies diluviennes"
> 100   →  "Inondations possibles"
```

## 3. Conseils et Recommandations

### 3.1 Structure des Conseils

```
Structure recommandée:
1. Action concrète
2. Moment/Condition (si applicable)
3. Raison (optionnel, court)

Exemple:
✅ "Évitez les sorties entre 11h et 16h (heures les plus chaudes)"
❌ "Il est recommandé d'éviter les activités extérieures pendant 
    les heures d'ensoleillement maximal en raison des risques 
    liés à l'exposition aux UV"
```

### 3.2 Conseils par Situation

#### Canicule (> 40°C)

```
✅ "Évitez les activités extérieures entre 11h et 16h"
✅ "Buvez de l'eau régulièrement (au moins 2L par jour)"
✅ "Portez des vêtements légers, clairs et amples"
✅ "Restez à l'ombre ou dans des endroits climatisés"
✅ "Ne laissez jamais personne dans une voiture au soleil"

❌ "Il est conseillé de limiter les efforts physiques pendant 
    les heures les plus chaudes de la journée"
❌ "Une hydratation adéquate est recommandée"
```

#### Sécheresse

```
✅ "Économisez l'eau potable"
✅ "Arrosez les cultures tôt le matin ou tard le soir"
✅ "Limitez les lessives et douches"

❌ "Il conviendrait de modérer sa consommation hydrique"
```

#### Inondation

```
✅ "Ne traversez pas les zones inondées"
✅ "Restez à l'écoute des autorités locales"
✅ "Préparez un sac d'urgence (papiers, médicaments, eau)"

❌ "Il est déconseillé de traverser les zones sujettes aux inondations"
```

#### Vague de Poussière

```
✅ "Portez un masque si vous devez sortir"
✅ "Fermez les fenêtres"
✅ "Évitez les activités sportives en extérieur"

❌ "Il est recommandé de se protéger les voies respiratoires"
```

## 4. Exemples Complets de Traduction

### Exemple 1: Bulletin Quotidien

```
❌ TECHNIQUE:
"La température maximale atteindra 41.3°C avec un point de rosée 
de 18°C. L'humidité relative sera de 23%. Le vent soufflera du 
secteur Ouest à 22 km/h avec des rafales à 35 km/h. La couverture 
nuageuse sera de 5%. La pression atmosphérique sera de 1015 hPa."

✅ SIMPLIFIÉ:
"Il fera très chaud aujourd'hui (41°C). L'air sera très sec. 
Vent d'Ouest à 22 km/h avec quelques rafales. Ciel dégagé, 
beau temps. Pression normale."

✅ TRÈS SIMPLE:
"Grande chaleur aujourd'hui (41°C). Ciel bleu, vent modéré. 
Sortez couvert et buvez beaucoup d'eau."
```

### Exemple 2: Alerte Météo

```
❌ TECHNIQUE:
"Un système dépressionnaire génère des précipitations convectives 
avec des cumuls attendus de 60-80mm sur 24h. Des rafales 
descendantes sont possibles."

✅ SIMPLIFIÉ:
"Alerte aux fortes pluies. Il pourrait tomber 60 à 80mm de pluie 
en 24h. Des coups de vent violents sont possibles."

✅ TRÈS SIMPLE:
"ALERTE PLUIE: Restez à l'abri. Très fortes pluies attendues. 
Ne sortez pas sauf urgence."
```

### Exemple 3: Prévisions Agricoles

```
❌ TECHNIQUE:
"L'évapotranspiration potentielle sera de 5mm/jour avec un 
déficit hydrique des sols de 15%. Les conditions sont défavorables 
pour les cultures pluviales."

✅ SIMPLIFIÉ:
"Les sols sèchent rapidement (5mm d'eau évaporée par jour). 
Les cultures sans irrigation souffrent du manque d'eau."

✅ TRÈS SIMPLE:
"Attention agriculteurs: les sols sont très secs. Arrosez si 
possible vos cultures."
```

## 6. Tests de Compréhension

### Questions à se poser

Avant de publier un bulletin, demandez-vous:

1. ✅ Ma grand-mère comprendrait-elle ce message ?
2. ✅ Un enfant de 10 ans saisirait-il l'essentiel ?
3. ✅ Les mots techniques sont-ils tous expliqués ?
4. ✅ Les conseils sont-ils actionnables immédiatement ?
5. ✅ Le message tient-il en 3 phrases maximum ?

### Test Utilisateur

```
Montrez le bulletin à 3 personnes non-initiées et demandez:
1. "Quelle température fera-t-il ?"
2. "Faut-il prendre un parapluie ?"
3. "Quels conseils dois-je suivre ?"

Si 2/3 répondent correctement → Bulletin validé
Sinon → Simplifier davantage
```
