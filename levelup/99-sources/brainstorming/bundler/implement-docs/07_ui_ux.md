# UI / UX

## 1. Rôle de l’interface
L’interface sert de poste de pilotage, non de vitrine.

## 2. Principes visuels
- sobriété ;
- densité contrôlée ;
- hiérarchie claire ;
- peu d’ornement ;
- concentration sur la progression et l’action ;
- lisibilité forte.

## 3. Structure d’écran stable
- header global ;
- navigation latérale ;
- contenu principal ;
- panneau contextuel secondaire.

## 4. Écrans minimum
- tableau de bord ;
- détail d’un plan ;
- détail d’un sujet ;
- séance en cours ;
- validation / résultat ;
- révision ;
- bibliothèque de ressources ;
- administration du contenu ;
- journal d’activité ;
- paramètres.

## 5. Système de design
- composants réutilisables ;
- états visuels clairs ;
- badges de statut ;
- cartes de progression ;
- tableaux de suivi ;
- filtres de recherche ;
- actions contextuelles ;
- alertes sobres.

## 6. UX fonctionnelle
- montrer la prochaine action ;
- montrer le pourquoi ;
- montrer le blocage éventuel ;
- montrer l’historique ;
- montrer l’avancement global.
