# Le Business Concept Model

Ce document sera probablement le plus important de toute la conception métier.

Son objectif ne sera pas de définir les fonctionnalités.

Il devra répondre à une seule question :

> **Quels sont les concepts qui existent dans l'univers de LevelUP et quelle est leur signification ?**

Par exemple, nous pourrions découvrir que :

* **Program** est un concept fondamental.
* **Routine** est un type particulier de Program.
* **University Schedule** est un Program importé.
* **Learning Path** est un Program spécialisé.
* **Domain** n'est pas un Program.
* **Competency** est une finalité, pas un contenu.
* **Resource** n'est jamais obligatoire ; elle est interchangeable.
* **Task** n'est qu'une unité d'exécution au sein d'un Program.

Ces décisions vont ensuite structurer toute l'architecture.
