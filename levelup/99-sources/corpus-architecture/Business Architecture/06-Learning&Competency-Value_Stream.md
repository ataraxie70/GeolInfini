# LevelUP

# Livrable 6 — Learning & Competency Value Stream

## (Flux de Création de Valeur de la Compétence)

**Référence : LEVELUP-BUS-002**

---

# 1. Objet du document

Ce document formalise le principal flux de création de valeur de LevelUP.

Il décrit comment une intention exprimée par un individu est progressivement transformée en une compétence réelle, démontrable et durable.

Ce document constitue le lien entre la philosophie du projet et les futures capacités métier. Il ne décrit ni une interface utilisateur, ni un scénario d'utilisation, mais le fonctionnement métier fondamental de LevelUP.

---

# 2. La création de valeur dans LevelUP

La valeur créée par LevelUP ne réside ni dans la diffusion de ressources pédagogiques, ni dans la simple gestion d'activités.

La valeur naît lorsque des ressources existantes sont organisées, exécutées, observées et validées afin de produire une compétence réellement exploitable.

Le flux de création de valeur est donc une transformation continue :

```text
Intention
        ↓
Organisation
        ↓
Progression
        ↓
Maîtrise
        ↓
Compétence démontrée
```

Le système n'a pas pour objectif de faire progresser un utilisateur dans un parcours.

Son objectif est de lui permettre d'acquérir une compétence qu'il pourra mobiliser dans une situation réelle.

---

# 3. Principe fondamental

Chaque parcours proposé par LevelUP poursuit une seule finalité :

> Transformer une intention d'apprentissage en une compétence démontrable.

La progression, les ressources, les programmes et les activités ne constituent que des moyens au service de cette transformation.

Une progression achevée sans compétence démontrée est considérée comme incomplète.

---

# 4. Flux principal de création de valeur

Le flux principal est constitué de dix étapes.

## Étape 1 — Définir une intention

Toute progression débute par une intention clairement exprimée.

Exemples :

* devenir administrateur système ;
* apprendre le développement Flutter ;
* préparer un concours ;
* suivre un semestre universitaire ;
* acquérir une compétence professionnelle.

Cette intention constitue le point de départ du parcours.

---

## Étape 2 — Identifier la compétence cible

À partir de l'intention, LevelUP identifie la compétence réellement recherchée.

La compétence cible représente le résultat attendu du parcours.

Elle est indépendante des ressources utilisées.

---

## Étape 3 — Structurer le domaine

Le domaine sélectionné est organisé selon les principes de LevelUP.

Cette structuration comprend notamment :

* les fondations ;
* les dépendances ;
* les sous-compétences ;
* les critères de maîtrise ;
* les validations attendues.

Cette organisation constitue le patrimoine intellectuel de LevelUP.

---

## Étape 4 — Construire le parcours

À partir de cette structure, un parcours cohérent est construit.

Le parcours respecte :

* les fondations ;
* les dépendances ;
* les objectifs intermédiaires ;
* la progression logique des apprentissages.

Le parcours privilégie toujours la solidité des acquis à la rapidité.

---

## Étape 5 — Organiser l'exécution

Le parcours est transformé en organisation opérationnelle.

Cette organisation peut prendre différentes formes :

* programme personnel ;
* emploi du temps universitaire ;
* formation professionnelle ;
* routine quotidienne ;
* plan hebdomadaire ;
* calendrier d'exécution.

LevelUP adapte l'organisation sans modifier la logique pédagogique.

---

## Étape 6 — Accompagner l'exécution

Pendant l'exécution, le système accompagne l'utilisateur.

Cet accompagnement repose sur :

* la discipline ;
* la régularité ;
* le suivi des activités ;
* le respect des objectifs ;
* l'adaptation du rythme lorsque cela est nécessaire.

Le rôle de LevelUP est d'orchestrer l'exécution sans se substituer à l'effort de l'apprenant.

---

## Étape 7 — Observer la progression

La progression est observée en continu.

L'observation ne mesure pas uniquement l'avancement.

Elle cherche également à comprendre :

* les acquis ;
* les difficultés ;
* les lacunes ;
* les points forts ;
* la stabilité des fondations.

Cette observation constitue la base de toute décision pédagogique.

---

## Étape 8 — Évaluer les acquis

À intervalles réguliers ou à la fin d'une étape importante, le système déclenche une évaluation.

Cette évaluation repose sur des situations représentatives du domaine étudié.

L'objectif n'est pas de vérifier la mémorisation mais de mesurer la capacité à mobiliser les connaissances dans un contexte concret.

---

## Étape 9 — Diagnostiquer et décider

À partir des résultats observés, LevelUP établit un diagnostic.

Ce diagnostic répond notamment aux questions suivantes :

* Les fondations sont-elles suffisamment solides ?
* Les objectifs attendus sont-ils atteints ?
* Quelles compétences sont réellement acquises ?
* Quelles lacunes persistent ?
* Les erreurs observées révèlent-elles un manque de compréhension fondamentale ?

Le système prend ensuite une décision pédagogique.

Cette décision peut consister à :

* poursuivre le parcours ;
* renforcer certains acquis ;
* organiser des révisions ciblées ;
* revenir sur une étape précédente ;
* déclencher une nouvelle évaluation.

La progression n'est jamais automatique.

Elle est conditionnée par la qualité réelle des acquis.

---

## Étape 10 — Démontrer la compétence

Une compétence est considérée comme acquise uniquement lorsqu'elle peut être démontrée dans un contexte réel.

La démonstration repose sur des preuves objectives.

Ces preuves peuvent prendre différentes formes :

* résolution d'une mission ;
* réalisation d'un projet ;
* étude de cas ;
* exercice pratique ;
* production technique.

La compétence démontrée marque la fin d'un cycle de progression.

Elle constitue également le point de départ des spécialisations futures.

---

# 5. Le cycle de maîtrise

Chaque étape importante du parcours est gouvernée par un cycle permanent.

```text
Étudier
      ↓
Pratiquer
      ↓
Mission
      ↓
Observation
      ↓
Évaluation
      ↓
Diagnostic
      ↓
Décision
      ├── Continuer
      ├── Renforcer
      ├── Réviser
      └── Réévaluer
```

Ce cycle garantit que la progression repose sur la maîtrise effective plutôt que sur la simple consommation de contenu.

---

# 6. Les missions comme mécanisme de validation

LevelUP privilégie les situations concrètes aux évaluations purement théoriques.

Chaque mission vise à démontrer une capacité opérationnelle.

Une mission n'a pas pour objectif de vérifier si une leçon a été lue.

Elle cherche à observer comment l'apprenant mobilise ses connaissances face à une situation représentative du domaine étudié.

Les missions constituent ainsi le principal mécanisme de validation des compétences.

---

# 7. Les Capability Statements

À la fin de chaque étape importante, LevelUP produit un état de compétence.

Cet état répond explicitement à deux questions.

## Ce que l'apprenant est désormais capable de faire

Le système décrit les capacités réellement démontrées.

Exemple :

* administrer les permissions d'un système Linux ;
* diagnostiquer un problème courant de système de fichiers ;
* monter et démonter un système de fichiers ;
* interpréter l'utilisation de l'espace disque.

## Ce qui n'est pas encore maîtrisé

Le système identifie également les compétences qui nécessitent encore un approfondissement avant d'aborder les étapes suivantes.

Cette approche fournit une représentation fidèle de la compétence réellement acquise.

---

# 8. Principes architecturaux

Le flux de création de valeur repose sur les principes suivants :

* une intention précède toujours un parcours ;
* une compétence précède toujours une spécialisation ;
* les fondations conditionnent toute progression ;
* la discipline et la rigueur accompagnent chaque étape ;
* les ressources sont des moyens et non une finalité ;
* les évaluations observent des capacités réelles ;
* la progression est adaptative ;
* les décisions pédagogiques reposent sur des observations objectives.

---

# 9. Décisions d'architecture

Les décisions suivantes sont désormais considérées comme fondamentales.

* Une progression n'est jamais automatiquement validée.
* Toute validation repose sur une démonstration observable.
* Les missions constituent le principal mécanisme d'évaluation des compétences.
* Les lacunes détectées entraînent un renforcement ciblé plutôt qu'une simple répétition du parcours.
* Les fondations sont systématiquement consolidées avant toute spécialisation.
* Chaque compétence acquise prépare naturellement l'accès à de nouvelles compétences.

---

# 10. Conclusion

Le Learning & Competency Value Stream décrit le moteur métier de LevelUP.

Il établit le processus par lequel une intention est transformée en compétence réelle grâce à une progression structurée, une organisation rigoureuse, une observation continue et une validation fondée sur la pratique.

Ce document constitue la référence qui guidera la conception du Business Capability Model, du Business Domain Model et de l'ensemble de l'architecture fonctionnelle de LevelUP.
