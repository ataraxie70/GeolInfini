# LevelUP — Spécification UI/UX Admin

## Rôle
L'espace admin pilote les parcours, les missions, les seuils, les pénalités et la supervision.

## Modules principaux
- Builder de parcours
- Importateur Markdown / JSON
- Calibration XP / niveaux
- Mission Builder
- Quiz Builder
- Supervision cohortes
- Journal système
- Gestion des parcours et modules

## Builder de parcours
Fonctions :
- créer un parcours
- structurer modules et topics
- définir les prérequis
- fixer les paliers
- visualiser le graphe

## Calibration
Réglages :
- XP par action
- seuils de niveau
- score minimal de maîtrise
- score de rétention
- délais de mission
- seuils de pénalité

## Supervision
Permet de voir :
- utilisateurs bloqués
- missions expirées
- points faibles récurrents
- taux de consolidation
- progression par cohorte
