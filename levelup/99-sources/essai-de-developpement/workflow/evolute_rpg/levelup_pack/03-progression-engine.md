# LevelUP — Progression Engine

## Principe
L'XP représente une preuve de progression réelle, pas une récompense vide.

## Actions récompensées
- topic validé
- QCM réussi
- session complétée
- mini-projet validé
- exercice correctif réussi
- révision utile
- mission complétée dans les temps

## Variables
### XP
Mesure de progression accumulée.

### Mastery Score
Score de maîtrise réelle sur 0-100.
Mesure :
- compréhension
- rétention
- application
- autonomie

### Discipline Score
Score comportemental sur 0-100.
Mesure :
- régularité
- retards
- missions ignorées
- révisions manquées

## Passage de niveau
Un niveau n'est débloqué que si :
- le seuil d'XP est atteint
- le score de maîtrise est suffisant
- la rétention est suffisante
- les prérequis sont validés

## Consolidation
Avant un niveau supérieur :
- réviser les bases
- relancer un QCM de rappel
- vérifier la mémoire long terme
- corriger les lacunes

## Pénalités
- retard léger -> rappel
- retard répété -> mission corrective
- échec répété -> baisse de discipline
- abandon -> blocage temporaire
- non consolidation -> verrouillage du niveau suivant
