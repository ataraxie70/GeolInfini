Construis le frontend MVP du projet Psycho-Pass.

Contraintes :
- Next.js + TypeScript.
- Tailwind CSS.
- Composants réutilisables.
- UI simple, lisible, sans surdesign.
- Respect strict du contrat API.
- Le frontend affiche l’état serveur et envoie les actions utilisateur.
- Aucune logique métier critique locale.

Pages minimales :
- accueil
- inscription / connexion
- tableau de bord
- liste des tests
- écran de passation du test
- écran résultat
- historique

À produire :
1. Structure des pages.
2. Composants partagés.
3. Gestion d’état minimale.
4. Appels API propres.
5. Gestion des erreurs et chargements.
6. Accessibilité de base.
7. Points d’intégration avec le backend.

Interdictions :
- Pas de calcul de score dans le client.
- Pas de dépendance inutile.
